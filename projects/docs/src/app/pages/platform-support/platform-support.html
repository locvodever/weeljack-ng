Angular and Optimus

Each WeeljackNg line is built on one Angular range and one Optimus UI line, and it is tested only against them.

The browser set below is Angular's own for this range, so it moves when the Angular pin, now {{ angular }}, moves.

Change detection

Every wj-* component is OnPush and correct without zone.js. These are hard rules, and every spec runs zoneless. An app that uses zone.js is neither tested nor blocked.

Server rendering

Server-side rendering is supported: no component touches a browser global outside afterNextRender or isPlatformBrowser, and a server-render smoke test covers every exported wj-* component.

Hydration is untested. An app that hits a hydration mismatch puts ngSkipHydration on the wj-* host.

Browsers

WeeljackNg supports exactly Angular's default browsers for the pinned Angular. Today that is baseline widely available on 2026-05-07:

  • Chrome, Edge and Firefox ≥ 119
  • Safari and iOS Safari ≥ 17.0

There is no .browserslistrc: neither the library nor this docs app ships one. Component CSS and DOM APIs stay inside that set.

Size

  • A wrapper weighs at most the larger of 2.5 KB or 25% of the Optimus entry it wraps.
  • An own entry, such as wj-sheet or wj-field, weighs at most 5 KB.
  • Both are measured as esbuild minify plus gzip level 6.
  • There is no app-level size, latency or load target.

Errors and warnings

An error that Optimus throws is never caught, swallowed or re-wrapped: it reaches your application's ErrorHandler exactly as Optimus threw it. WeeljackNg's own problems are development-only console.warn lines in this shape: a code, the selector, what is wrong, what to do, and where to find more.
