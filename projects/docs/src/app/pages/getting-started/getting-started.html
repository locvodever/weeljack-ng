Install

npm installs the peer dependencies below along with weeljack-ng, so your app lists only weeljack-ng in its package.json. The peer ranges are:

  • {{ peer[0] }}&ngsp;{{ peer[1] }}

Provide

Add provideWeeljack() to your application config, once.

Never call provideOptimus. provideWeeljack already calls it once, inside. A second call silently overwrites the prefix, the layer and the dark-mode setting that WeeljackNg set, so the components lose their theme. In development mode, a wj-* component warns when the theme has lost the wj prefix (WJ0002).

A first component

Import the component from its own entry, weeljack-ng/button for wj-button, and use it in a template.

Another language

The strings WeeljackNg renders itself are English by default. To switch them to Vietnamese, pass vi from weeljack-ng/locale as the translation option.

WeeljackNg sets neither LOCALE_ID nor <html lang>. Both stay yours.

Keep Optimus out of your imports

An app never imports @openng/*: everything it needs comes from weeljack-ng. npm puts the Optimus packages in your tree as peers, so only lint stops a direct import. Once no @openng import is left in your app, paste this rule into your flat config.

Flat config keeps only the last no-restricted-imports options for a file. A block added as its own config object replaces any no-restricted-imports you already set for the same files, so if you have one, merge this pattern into it instead.

Compatibility

WeeljackNg numbers its own lines. Each line names the Angular range and the Optimus UI line it builds on.
