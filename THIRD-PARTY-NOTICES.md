# Third-party notices

WeeljackNg is MIT-licensed (see [LICENSE](LICENSE)). This file lists, per upstream package, the
files in this repository that were copied or adapted from it, together with the upstream licence
text and copyright lines.

A file that only imports, wraps or configures Optimus UI is not a copy and is not listed here.

No file has been adapted from an upstream package yet. An entry is added in the same change that
adds the first adapted file, in this shape:

- the upstream package and version (for example `@openng/optimus-ui` 2.0.2);
- the WeeljackNg files adapted from it;
- the full MIT text with the upstream copyright lines, verbatim.
